Setup trước hackathon

Máy mới, ngày đầu

Nhận máy → cài Claude → nối GitHub → dán một prompt và để nó tự cài. Trang này dùng chung cho cả macOS và Windows: chọn hệ điều hành ở góc trên, cả trang sẽ chỉ hiện lệnh của máy bạn.

Ba bước, khoảng 20 phút

Mục 01 · ~15 phút Claude + GitHub Cài Claude, tạo tài khoản GitHub, nối hai cái lại để AI đọc được code công ty. Toàn bộ bằng chuột.
Mục 02 · ~5 phút Cài 2 app VS Code + GitHub Desktop. Dán một đoạn lệnh là xong, kèm phần chứng minh lệnh đó an toàn.
Checklist bên phải Tick khi xong Luôn hiện ở cạnh phải màn hình. Xong một nhóm thì nhóm đó tự thu lại cho gọn.

Cần xin trước

  1. Tài khoản Claude của công ty — nhắn Team Lead.
  2. Lời mời vào GitHub của công ty — gửi họ tên tài khoản GitHub sau khi tạo ở mục 01.
  3. Điện thoại có app xác thực — Google Authenticator, Microsoft Authenticator hoặc 1Password. GitHub bắt buộc bảo mật 2 lớp.

01

Hướng dẫn cho người mới

Không cần biết lập trình, không cần gõ lệnh. Khoảng 20 phút, làm 3 việc: cài Claude, tạo tài khoản GitHub, nối hai cái lại.

Phần A Cài Claude

  1. Tải bản macOS tại claude.ai/download, mở file rồi kéo icon Claude vào thư mục Applications.
  2. Tải bản Windows tại claude.com/download, chạy file cài đặt, bấm Next → Install.
  3. Mở app → Sign in → trình duyệt mở ra → đăng nhập bằng tài khoản Claude công ty cấp → quay lại app.
  4. Thấy khung chat và gõ được câu hỏi vào đó là xong.

Phần B Tạo tài khoản GitHub

GitHub là gì? Nơi cả công ty lưu và chia sẻ code, giống Google Drive nhưng dành cho code — có lưu lịch sử ai sửa gì, lúc nào, vì sao.

B1 · Đăng ký

  1. Vào github.com/signup, đăng ký bằng email công ty.
  2. Đặt tên tài khoản dễ nhận: an-nguyen, chien-nv… Cả team nhìn thấy tên này hằng ngày.
  3. Mở hộp thư, bấm link xác nhận email.

B2 · Bật bảo mật 2 lớp — bắt buộc

  1. Vào github.com/settings/security → Enable two-factor authentication.
  2. Chọn Authenticator app → mở app xác thực trên điện thoại → quét mã QR → nhập 6 số.
Lưu mã dự phòng ngay

Màn hình tiếp theo hiện một danh sách recovery codes. Cất vào trình quản lý mật khẩu hoặc in ra. Mất điện thoại mà không có mấy mã này là mất tài khoản vĩnh viễn, không ai lấy lại hộ được.

B3 · Vào tổ chức của công ty

  1. Gửi tên tài khoản GitHub cho Team Lead.
  2. Nhận email mời → mở → Join organization.
  3. Công ty dùng đăng nhập nội bộ (SSO) thì trình duyệt hỏi thêm một bước → Authorize.

Phần C Nối GitHub vào Claude

Nối xong bạn hỏi được kiểu: "Đọc repo dự án X rồi giải thích chức năng thanh toán hoạt động thế nào" · "Viết giúp tôi tài liệu mô tả module này cho người mới".

Kết nối này để AI đọc code, không phải để nó cài đặt

Nó không cài phần mềm hộ bạn và không sửa code trên máy bạn. Muốn vậy thì dùng tab Code ở mục 03.

Trong Claude

  1. Mở tab Chat → bấm dấu + ở góc dưới bên trái khung chat.
  2. Chọn Add from GitHub.
  3. Lần đầu, nó chuyển sang GitHub xin quyền → chọn Only select repositories và tick đúng repo cần dùng (an toàn hơn All repositories).
  4. Quay lại Claude → tìm repo theo tên hoặc dán link repo → dùng bộ duyệt file chọn thư mục/file cần đọc.

Hai nút hay dùng sau đó: Sync (repo có code mới thì bấm để Claude đọc bản mới nhất — nó không tự cập nhật) và Configure files (đổi danh sách file).

Dùng lại nhiều lần cho cùng một dự án: tạo một Project rồi thêm repo vào Project knowledge (dấu + ở góc trên bên phải phần đó → GitHub). Từ đó mọi chat trong Project đều có sẵn code.

Giới hạn cần biết
  • Claude chỉ đọc tên file và nội dung file trên một nhánh.
  • Không đọc lịch sử chỉnh sửa, không đọc Pull Request, không đọc bình luận.
  • Repo riêng tư của công ty có SSO thì quản trị viên phải duyệt — không thấy repo hiện ra thì nhắn Team Lead.

Trong ChatGPT (nếu bạn cũng dùng)

  1. Settings → Apps → tìm GitHub → bấm kết nối.
  2. Nó chuyển sang GitHub để cài và cấp quyền → chọn repo cho phép truy cập.
  3. Đổi danh sách repo sau này: Settings → Apps → GitHub → Choose repositories.
Giới hạn cần biết
  • Nối xong repo thường mất khoảng 5 phút mới hiện ra. Chưa thấy thì đợi rồi tải lại trang.
  • Công ty có thể chặn — vào Settings → Apps → GitHub → bánh răng bấm Request để xin duyệt.
Đến đây là đủ nếu bạn chỉ cần đọc code và hỏi đáp

02

Cài VS Code + GitHub Desktop

Một đoạn lệnh dán vào là cài xong cả 2 app, kèm phần chứng minh vì sao đoạn lệnh đó an toàn để bạn tự kiểm tra trước khi chạy.

Dán vào đâu

TerminalPowerShell hoặc tab Code của Claude. Tab Cowork không dùng được cho việc này — nó chạy trên máy chủ ở xa nên không cài phần mềm lên máy bạn được.

Dán vào Terminal

Mở Terminal: bấm Cmd + dấu cách, gõ Terminal, Enter. Copy toàn bộ khối dưới, dán vào, bấm Enter. Chạy mất 2–4 phút.

macOS · cài cả 2 app
#!/bin/bash
set -euo pipefail

# Cài Visual Studio Code + GitHub Desktop từ trang chủ của Microsoft và GitHub.
# Không dùng sudo. Không tải script lạ. Kiểm tra chữ ký số trước khi cài.

if [ "$(uname -m)" = "arm64" ]; then
  VSCODE_URL="https://update.code.visualstudio.com/latest/darwin-arm64/stable"
  GHD_URL="https://central.github.com/deployments/desktop/desktop/latest/darwin-arm64"
else
  VSCODE_URL="https://update.code.visualstudio.com/latest/darwin-universal/stable"
  GHD_URL="https://central.github.com/deployments/desktop/desktop/latest/darwin"
fi

TMP="$(mktemp -d)"
trap 'rm -rf "$TMP"' EXIT

cai_app() {
  ten="$1"; url="$2"; app="$3"

  if [ -d "/Applications/$app" ] || [ -d "$HOME/Applications/$app" ]; then
    echo "✅ $ten đã có sẵn trên máy, bỏ qua."
    return
  fi

  echo "==> Đang tải $ten ..."
  curl -fL --proto '=https' --tlsv1.2 -o "$TMP/app.zip" "$url"

  echo "==> Đang giải nén ..."
  mkdir -p "$TMP/out"
  # Dùng ditto (công cụ gốc của macOS), KHÔNG dùng unzip:
  # unzip làm hỏng chữ ký của app, khiến bước kiểm tra bên dưới báo lỗi oan.
  ditto -x -k "$TMP/app.zip" "$TMP/out"
  src="$(find "$TMP/out" -maxdepth 1 -name '*.app' -print -quit)"

  echo "==> Kiểm tra chữ ký số (nếu bước này fail thì DỪNG, đừng cài) ..."
  codesign --verify --strict "$src"
  spctl --assess --type execute "$src"
  echo "    Chữ ký hợp lệ:"
  codesign -dv --verbose=2 "$src" 2>&1 | grep -E '^(Authority|TeamIdentifier)=' || true

  echo "==> Đang chép vào thư mục Applications ..."
  if cp -R "$src" /Applications/ 2>/dev/null; then
    echo "✅ $ten đã cài vào /Applications"
  else
    mkdir -p "$HOME/Applications"
    cp -R "$src" "$HOME/Applications/"
    echo "✅ $ten đã cài vào ~/Applications (thư mục riêng của bạn)"
  fi

  rm -rf "$TMP/out" "$TMP/app.zip"
}

cai_app "Visual Studio Code" "$VSCODE_URL" "Visual Studio Code.app"
cai_app "GitHub Desktop"     "$GHD_URL"    "GitHub Desktop.app"

echo ""
echo "🎉 Xong. Mở Launchpad là thấy 2 app mới."
Đã có Homebrew rồi?

Thì chỉ cần một dòng — kết quả như nhau. Cask tên github chính là GitHub Desktop.

macOS · nếu đã có Homebrew
brew install --cask visual-studio-code github

Dán vào PowerShell

Bấm nút Start, gõ PowerShell, Enter. Copy toàn bộ khối dưới, dán vào, bấm Enter. App nào đã cài rồi thì winget tự bỏ qua.

Windows · cài cả 2 app
$ErrorActionPreference = 'Stop'

# Cài Visual Studio Code + GitHub Desktop từ trang chủ của Microsoft và GitHub.
# Ưu tiên winget (có sẵn trong Windows). Không có winget thì tải thẳng và kiểm tra chữ ký số.

$apps = @(
  @{ Ten='Visual Studio Code'; Id='Microsoft.VisualStudioCode';
     Url='https://update.code.visualstudio.com/latest/win32-x64-user/stable'; File='VSCodeUserSetup.exe' },
  @{ Ten='GitHub Desktop';     Id='GitHub.GitHubDesktop';
     Url='https://central.github.com/deployments/desktop/desktop/latest/win32'; File='GitHubDesktopSetup.exe' }
)

$coWinget = $null -ne (Get-Command winget -ErrorAction SilentlyContinue)
if (-not $coWinget) {
  Write-Host "Máy chưa có winget, sẽ tải thẳng từ trang chủ." -ForegroundColor Yellow
}

foreach ($a in $apps) {
  Write-Host ""
  Write-Host "==> $($a.Ten)" -ForegroundColor Cyan

  if ($coWinget) {
    winget install --id $a.Id -e --source winget `
      --accept-package-agreements --accept-source-agreements
  }
  else {
    $file = Join-Path $env:TEMP $a.File
    Write-Host "    Đang tải ..."
    Invoke-WebRequest -Uri $a.Url -OutFile $file

    Write-Host "    Kiểm tra chữ ký số ..."
    $sig = Get-AuthenticodeSignature $file
    if ($sig.Status -ne 'Valid') {
      throw "❌ Chữ ký KHÔNG hợp lệ ($($sig.Status)). Dừng lại, không cài."
    }
    Write-Host "    Chữ ký hợp lệ. Nhà phát hành: $($sig.SignerCertificate.Subject)"

    Start-Process -FilePath $file -Wait
    Remove-Item $file -Force
  }
  Write-Host "✅ $($a.Ten) xong."
}

Write-Host ""
Write-Host "🎉 Xong. Bấm Start là thấy 2 app mới." -ForegroundColor Green

Hoặc để Claude Code làm hộ

Prompt · dán vào tab Code
Cài giúp tôi Visual Studio Code và GitHub Desktop lên máy này.

Yêu cầu bắt buộc:
- Tự phát hiện máy tôi là macOS hay Windows và dùng đúng cách của máy đó.
- macOS: nếu máy đã có Homebrew thì dùng `brew install --cask visual-studio-code github`.
  Chưa có Homebrew thì tải thẳng từ trang chủ, ĐỪNG cài Homebrew (tôi không muốn cài thêm thứ tôi chưa cần):
    VS Code        https://update.code.visualstudio.com/latest/darwin-universal/stable
    GitHub Desktop https://central.github.com/deployments/desktop/desktop/latest/darwin
  (máy Apple Silicon thì đổi darwin-universal thành darwin-arm64, và darwin thành darwin-arm64)
- Windows: dùng winget
    winget install --id Microsoft.VisualStudioCode -e --source winget
    winget install --id GitHub.GitHubDesktop -e --source winget
- App nào đã có trên máy thì bỏ qua, không cài đè. Kiểm tra trước khi cài.
- KHÔNG dùng sudo / KHÔNG xin quyền admin. Nếu bắt buộc phải cần thì dừng lại hỏi tôi và giải thích vì sao.
- KHÔNG tải script từ bất kỳ domain nào ngoài microsoft.com, visualstudio.com, github.com.
- Trước khi cài, kiểm tra chữ ký số của file tải về (macOS: codesign + spctl, Windows: Get-AuthenticodeSignature). Chữ ký không hợp lệ thì DỪNG, báo cho tôi, không cài.
- KHÔNG đụng vào file cá nhân của tôi, KHÔNG đọc ~/.ssh, KHÔNG tắt bất kỳ cơ chế bảo mật nào.
- Trước mỗi lệnh, nói cho tôi biết lệnh đó làm gì bằng tiếng Việt.
- Xong thì báo cáo: mỗi app đã cài phiên bản nào, nằm ở đâu.

Vì sao đoạn lệnh trên an toàn

Bạn không cần tin ai — dưới đây là những gì tự kiểm chứng được.

1 · Không có sudo, không xin quyền quản trị

Bản Mac chép app vào /Applications, không được thì tự chuyển sang ~/Applications — thư mục riêng của bạn. Không chỗ nào đòi mật khẩu máy.

2 · Không có kiểu curl … | bash

Đây là dạng nguy hiểm nhất: tải file lạ từ mạng về chạy thẳng mà không ai đọc được nội dung. Đoạn lệnh trên chỉ tải file cài đặt của chính 2 app đó, còn toàn bộ lệnh thì bạn đang đọc bằng mắt.

3 · Chỉ tải từ tên miền chính chủ

update.code.visualstudio.com → chuyển tiếp sang vscode.download.prss.microsoft.com (CDN Microsoft) · central.github.com → desktop.githubusercontent.com (CDN GitHub). Tự kiểm tra: dán link vào trình duyệt xem nó chuyển đi đâu. Thấy tên miền khác → đừng chạy, báo team.

4 · Bắt buộc kiểm tra chữ ký số trước khi cài

Mac dùng codesign + spctl, Windows dùng Get-AuthenticodeSignature. File bị chỉnh sửa dọc đường thì bước này fail và script dừng ngay, chưa cài gì cả.

5 · Không tắt bất kỳ cơ chế bảo vệ nào

Không spctl --master-disable, không tắt Gatekeeper, không Set-ExecutionPolicy Bypass, không loại trừ thư mục khỏi Windows Defender. Ai bảo bạn làm mấy cái đó để "cài cho nhanh" — từ chối.

6 · Không chạm vào dữ liệu của bạn

Chỉ tải 2 file vào thư mục tạm, giải nén, chép 2 app, rồi tự xoá thư mục tạm. Không đọc file cá nhân, không đụng ~/.ssh, không gửi gì ra ngoài.

Cách tự kiểm tra bất kỳ đoạn lệnh nào

Kỹ năng này quan trọng hơn cả trang này. Dán lệnh lạ vào Terminal là một trong những cách bị chiếm máy phổ biến nhất hiện nay — kẻ xấu hay gửi kèm câu "chạy cái này để sửa lỗi".

Bắt AI đọc hộ trước khi chạy

Prompt kiểm tra · dán kèm đoạn lệnh cần soi
Đọc đoạn lệnh dưới đây và trả lời tôi bằng tiếng Việt:
1. Nó làm chính xác những gì với máy tôi? Liệt kê từng việc.
2. Nó tải dữ liệu từ những tên miền nào? Có tên miền nào không phải trang chủ chính thức không?
3. Nó có xin quyền quản trị (sudo/admin) không? Để làm gì?
4. Nó có đọc, sửa, xoá hay gửi đi file cá nhân nào của tôi không?
5. Nó có tắt cơ chế bảo mật nào không?
6. Có gì đáng ngờ không? Trả lời thẳng: NÊN CHẠY hay KHÔNG NÊN CHẠY.

[dán đoạn lệnh vào đây]
Dấu hiệu đỏ — thấy là dừng, đi hỏi team
  • curl … | bash hoặc irm … | iex từ tên miền bạn không nhận ra
  • sudo mà không giải thích tại sao cần
  • Chuỗi dài loằng ngoằng khó đọc, base64 -d, eval — thường là để giấu lệnh thật
  • Đụng vào ~/.ssh, .env, ~/.aws, Keychain, trình duyệt, ví tiền điện tử
  • rm -rf vào đường dẫn rộng như ~/, /, C:\
  • chmod 777, tắt Gatekeeper / Defender / ExecutionPolicy
  • Gửi dữ liệu đi đâu đó: curl -d @file https://…
  • Người gửi giục "chạy nhanh lên", "đừng hỏi ai", "khẩn cấp"
Ghi chú cho nhất quán

Hướng dẫn cài Claude Code bằng terminal có dùng curl … | bash và irm … | iex. Đó đúng là dạng lệnh cần cảnh giác — nó chấp nhận được chỉ vì tải từ claude.ai, tên miền chính chủ của Anthropic. Không thoải mái thì tải app desktop ở claude.ai/download, kết quả như nhau.
